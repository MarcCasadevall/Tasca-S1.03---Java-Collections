📌 Ejercicios

Ejercicio 1 — Duplicados:

Clase Month y manejo de ArrayList y HashSet.

Insertar meses, comprobar orden y evitar duplicados.

Ejercicio 2 — ListIterator:

Crear y manipular listas (List<Integer>).

Añadir elementos en orden inverso usando ListIterator.

Ejercicio 3 — Capital Game:

Leer countries.txt y guardar país → capital en HashMap.

Juego de 10 preguntas aleatorias al usuario.

Contabilizar puntuación y guardar resultados en classificacio.txt.

🛠 Tecnologías

Java 17

IntelliJ IDEA

Ficheros .txt para datos

🚀 Cómo ejecutar

Clonar el repositorio:

git clone <URL_DEL_REPOSITORIO>


Asegurarse de tener countries.txt en la ruta indicada en el código.

Ejecutar Main.java.

Introducir el nombre del usuario y responder las 10 preguntas.

Consultar classificacio.txt para ver la puntuación.

✨ Funcionalidades principales

Manejo de ArrayList, HashSet y ListIterator.

Juego interactivo con HashMap y selección aleatoria.

Lectura y escritura segura de ficheros (BufferedReader / BufferedWriter).

Métodos static para simplificar ejecución desde main.
